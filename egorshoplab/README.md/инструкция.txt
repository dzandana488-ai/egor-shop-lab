# Егор Шоп — лабораторная работа № 2

Учебное веб-приложение на Python, Flask и SQLite.

В проекте представлены:
- SQL-инъекция в поиске товаров;
- хранимая XSS в отзывах;
- Python-скрипты для демонстрации;
- исправленная версия приложения;
- файл исправлений fix.patch.

Приложение предназначено для локального запуска на 127.0.0.1.

## Структура

- vulnerable/ — уязвимая версия.
- fixed/ — исправленная версия.
- exploits/ — скрипты демонстрации.
- fix.patch — изменения, устраняющие обе уязвимости.
- requirements.txt — зависимости.

## Установка

Откройте PowerShell в корневой папке проекта.

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск уязвимой версии

При первом запуске создайте базу и таблицы:

```powershell
.\.venv\Scripts\python.exe vulnerable\init_db.py
.\.venv\Scripts\python.exe vulnerable\create_reviews.py
```

init_db.py следует выполнять один раз для каждой новой базы.
Повторный запуск добавляет товары повторно.

Запустите сервер:

```powershell
.\.venv\Scripts\python.exe vulnerable\app.py
```

Откройте http://127.0.0.1:5000/ в браузере.

Оставьте сервер работающим. Команды проверки выполняйте
во втором терминале из корня проекта.

## Демонстрация SQL-инъекции

В exploit_sqli.py должно быть:

```python
payload = "' OR 1=1 -- "
```

Запустите:

```powershell
.\.venv\Scripts\python.exe exploits\exploit_sqli.py
```

Ожидаемый результат: HTML-ответ содержит все товары,
несмотря на отсутствие товара с введённым названием.

Для сравнения замените payload на "Чай" и повторите запуск.
В ответе будет только чай.

Причина: приложение склеивает SQL-запрос с пользовательским
вводом. Введённое условие OR 1=1 становится частью SQL-кода.

## Демонстрация хранимой XSS

Запустите:

```powershell
.\.venv\Scripts\python.exe exploits\exploit_xss.py
```

Скрипт отправляет отзыв с тестовым JavaScript методом POST,
затем запрашивает главную страницу и проверяет наличие
неэкранированного кода в HTML.

Откройте или обновите страницу магазина в браузере.
Ожидается окно с сообщением «XSS из Python!».

Сам HTTP-скрипт не выполняет JavaScript:
выполнение проверяется в браузере.

Причина: фильтр safe в шаблоне отключает экранирование
текста отзыва. Сохранённый ввод интерпретируется как HTML.

Каждый запуск скрипта добавляет новый тестовый отзыв.

## Проверка исправленной версии

Остановите уязвимый сервер сочетанием Ctrl+C.
Обе версии используют один порт и запускаются по очереди.

При первом запуске исправленной версии создайте её базу:

```powershell
.\.venv\Scripts\python.exe fixed\init_db.py
.\.venv\Scripts\python.exe fixed\create_reviews.py
```

Запустите:

```powershell
.\.venv\Scripts\python.exe fixed\app.py
```

Повторите запуск обоих скриптов из второго терминала.

Ожидаемые результаты:
- обычный поиск "Чай" работает;
- SQL-инъекция не возвращает товары;
- XSS-отзыв сохраняется и отображается как текст;
- JavaScript из отзыва не выполняется.

Исправления:
1. В поиске используется параметризованный SQL-запрос.
2. Из HTML-шаблона удалён фильтр safe для текста отзыва.

## Файл исправлений

fix.patch содержит различия между уязвимым и исправленным кодом:
- строки с минусом удаляются;
- строки с плюсом добавляются.

При установленном Git патч можно применить к копии
уязвимой версии. Из корня проекта:

```powershell
Copy-Item -Recurse vulnerable patched
Set-Location patched
git apply --check ../fix.patch
git apply ../fix.patch
Set-Location ..
```

Первую команду выполняйте, когда папки patched ещё нет.
git apply --check проверяет возможность применения патча.
После применения код в patched должен содержать исправления.

## Ограничения демонстрации

Каталог товаров общедоступен. SQL-инъекция в этой работе
демонстрирует изменение условия поиска, а не получение
секретных данных.

XSS демонстрируется всплывающим сообщением без передачи данных.
